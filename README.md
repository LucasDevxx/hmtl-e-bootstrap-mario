# CyberEcho

Projeto acadêmico desenvolvido utilizando HTML e Bootstrap 5.

O objetivo do trabalho foi criar uma página web utilizando ferramentas e componentes do Bootstrap.

O tema de cibersegurança foi escolhido pelos alunos para representar visualmente o site.

---

# Tecnologias Utilizadas

* HTML5
* Bootstrap 5

---

# Componentes Bootstrap Utilizados

Durante o desenvolvimento foram utilizados componentes e classes do Bootstrap, como:

* Navbar
* Grid System
* Botões
* Containers
* Responsividade
* Imagens responsivas

---
