"# hmtl-e-bootstrap-mario" 
CyberEcho

Projeto acadêmico desenvolvido utilizando HTML5, CSS3 e Bootstrap 5.

O objetivo do projeto é apresentar uma interface moderna utilizando recursos responsivos do Bootstrap e estilização personalizada em CSS.

Sobre o Projeto

O CyberEcho foi criado como trabalho acadêmico com o objetivo de demonstrar a utilização das ferramentas e componentes do framework Bootstrap no desenvolvimento de páginas web responsivas.

O tema de cibersegurança foi escolhido pelos alunos para representar o projeto visualmente.

O site apresenta:

Navbar responsiva
Sessão inicial (Hero Section)
Cards de projetos
Sessão de equipe
Footer estilizado
Layout moderno e responsivo
Objetivo do Trabalho

O trabalho teve como objetivo praticar e aplicar as ferramentas do Bootstrap 5 no desenvolvimento front-end.

Durante o projeto foram utilizados:

Sistema de Grid
Navbar responsiva
Botões
Containers
Responsividade
Classes utilitárias
Componentes visuais do Bootstrap

O projeto também utilizou CSS personalizado para complementar a estilização da interface.
